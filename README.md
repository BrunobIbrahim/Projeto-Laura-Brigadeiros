# 🍫 Laura Brigadeiros

> Site institucional desenvolvido para a **Laura Brigadeiros**, uma marca especializada em brigadeiros artesanais e doces para momentos especiais.

---

## 📚 Sobre o projeto

Este projeto está sendo desenvolvido para a **Laura Brigadeiros**, sendo meu primeiro projeto criado para uma empresa real.

O objetivo é desenvolver um site para apresentar a marca, seus produtos, sabores, tamanhos, preços e formas de contato com os clientes.

O projeto também representa uma etapa importante na minha evolução como desenvolvedor, permitindo aplicar na prática conhecimentos de **HTML e CSS** em um projeto com uma finalidade real.

---

## ✨ Funcionalidades

- Apresentação da marca
- Seção "Sobre"
- Cardápio de produtos
- Categorias e sabores
- Informações sobre tamanhos e preços
- Seção de contato e reservas
- Link direto para contato pelo WhatsApp
- Navegação entre as seções da página
- Layout responsivo para diferentes tamanhos de tela

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

---

## 🎨 Design

O layout está sendo desenvolvido de acordo com a identidade visual da **Laura Brigadeiros**, buscando manter uma apresentação organizada e consistente entre as diferentes seções do site.

A estrutura, as cores, a tipografia e os elementos visuais estão sendo trabalhados para destacar os produtos e facilitar a navegação e o acesso às informações da marca.
